set up in 2 minutes

  1. download the zip
  2. unzip it anywhere on your computer
  3. open chrome://extensions
  4. turn on "developer mode" (top right)
  5. click "load unpacked" — select the folder
  6. click the HB icon in your toolbar
  7. add your messages, set daily limit, toggle ON
  8. leave instagram open. that's it. go do literally anything else.
