get started

install in 2 minutes

  1. download the zip
  2. unzip it anywhere
  3. open chrome://extensions
  4. turn on developer mode (top right)
  5. click "load unpacked" and select the folder
  6. click the HB icon in your toolbar
  7. add your messages, set a daily limit, toggle on
  8. leave instagram open. go do your thing.
